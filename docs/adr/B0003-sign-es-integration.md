# ADR B0003 · Integración SIGN ES

Estado: Propuesto

La emisión fiscal de Billka se diseñará para integrarse con SIGN ES cuando exista cliente/piloto que lo justifique.

> **Revisado por `B0012` (10-nov-2026)**: Billka no emite, así que SIGN ES deja de ser un canal de
> emisión. Si aparece, será para firmar constancias o para sellado de tiempo, nunca para expedir
> facturas.
